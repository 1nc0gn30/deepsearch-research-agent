## How This Artifact Was Generated

### 1. Command Line Interface (CLI)
```bash
deepsearch run \
  --query "Autonomous Enterprise AI Agents Market Size, Architecture Standards, Protocol Adoption & Competitive Landscape 2024–2028" \
  --depth deep \
  --focus-domains "gartner.com,idc.com,forrester.com,mckinsey.com,modelcontextprotocol.io,hai.stanford.edu,nist.gov" \
  --output-dir ./examples/market-intelligence-report \
  --format all
```

### 2. Python Programmatic API
```python
from deepsearch_research_agent import DeepResearchEngine, ResearchConfig

config = ResearchConfig(
    depth="deep",
    investigation_angles=[
        "Market Sizing & TAM Projections",
        "Protocol Standardization & MCP Ecosystem",
        "Multi-Agent Topologies & Orchestration",
        "Enterprise Governance, Security & Risk",
        "Hard ROI Metrics & Production Case Studies",
    ],
    min_source_authority=85,
)

engine = DeepResearchEngine(config=config)
result = engine.run(
    query="Autonomous Enterprise AI Agents Market Size, Architecture Standards & ROI (2024-2028)"
)

result.save_markdown("ai_agents_market_2026.md")
result.save_sources_json("sources.json")
```
