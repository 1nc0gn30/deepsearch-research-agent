## How This Artifact Was Generated

### 1. Command Line Interface (CLI)
```bash
deepsearch run \
  --query "State of Fault-Tolerant Quantum Computing & Logical Qubit Scaling (2026)" \
  --depth exhaustive \
  --breadth 8 \
  --focus-domains "nature.com,science.org,aps.org,ieee.org,arxiv.org" \
  --output-dir ./examples/quantum-computing-brief \
  --format all
```

### 2. Python Programmatic API
```python
from deepsearch_research_agent import DeepResearchEngine, ResearchConfig

config = ResearchConfig(
    depth="exhaustive",
    max_subqueries_per_stage=4,
    enable_consensus_matrix=True,
    min_source_authority=80,
)

engine = DeepResearchEngine(config=config)
result = engine.run(
    query="State of Fault-Tolerant Quantum Computing & Logical Qubit Scaling (2026)"
)

# Export all formats
result.save_markdown("research_report.md")
result.save_html("report.html")
result.save_json("data_bundle.json")
```
